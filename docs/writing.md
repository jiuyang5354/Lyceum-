# 写作分项评分

数学题可以对答案，作文不能。但作文也不是只能交给模型拍脑袋——**篇幅、结构、连贯、句式**这四件事可以确定性地算出来，而且能说清「为什么扣分」。

## 每条结论都要带证据

不是「结构 3 分」，而是：

```
篇幅   4/25   117 远低于目标（20%）
结构  25/25   3 段，平均每段 2.0 句
连贯  25/25   过渡词 4 处（每百词约 3.4 处）
句式  25/25   平均句长 19.5，长短有变化（标准差 3.6）
```

证据由规则生成，可复现、可单测，不经过模型。

## 四个形式维度（各 25 分）

| 维度 | 英语 | 语文 |
|---|---|---|
| 篇幅 | 词数 / 学段目标（40 / 80 / 120） | 汉字数 / 目标（300 / 600 / 800） |
| 结构 | 段数 ≥ 3 且每段 ≥ 2 句 | 同 |
| 连贯 | 过渡词密度（however/therefore/because…） | 过渡词（因此/然而/首先/总之…） |
| 句式 | 平均句长 8–22 词，长度有变化 | 平均句长 12–45 字，长度有变化 |

## 内容维度：模型或老师，且必须标明来源

`use_model=true` 时调用一次模型，评「内容切题/语言质量」（语文为「内容立意/语言表达」），各 25 分。
每条结果带 `source: "model"`，理由必须指向文本具体位置；模型返回不完整、解析失败、未配置时**静默降级**为只有形式维度，并在 `notes` 里写明，不冒充评过内容。

`coverage` 字段直接说清这次覆盖到哪一层：`仅形式维度` / `形式 + 内容`。

## 三条提示（不计分）

除了分数，还会给三条能确定判的线索，用来提醒而不是评判：

| 提示 | 判据 | 例子 |
|---|---|---|
| 首尾点题 | 题目与首段/末段的**最长公共片段** ≥ 2 字 | 首/尾段呼应题目：一次难忘的经历 |
| 具体事例 | 出现时间词（去年、那天、第一次…）或数字 | 出现时间或数量线索 |
| 写出感受 | 出现「我发现／我明白／让我／收获…」 | 出现「我发现」 |

判不了的（立意高不高、文采好不好）不放进提示里。

## 记录与趋势

每次评阅存入 `writing_reviews` 表（学科、学段、题目、正文、总分、各维、提示、时间）。
`POST /api/writing/review` 返回里带 `id` 和 `history`（最近 8 次），界面上画成柱状趋势：

```
最近 5 次   79   80   33   42   80
```

`GET /api/writing/history?subject=语文` 可单独取历史。

## 接口

```
POST /api/writing/review
{"subject":"语文","band":"middle","task":"记一次难忘的经历","text":"…","use_model":false}
→ {"total":79,"max":100,"coverage":"仅形式维度",
   "dims":[{key,name,score,max,source,evidence},…],
   "features":{units,sentences,paragraphs,avg_sentence,sentence_sd,connectives,punct_kinds},
   "notes":["未启用模型评分：本次只覆盖…"]}
```

界面在学习记录页底部：选学科/学段、填题目、贴作文 → 评一评；勾选「让模型评内容」才会多一次调用。

## 语义切题（默认关闭）

「首尾点题」那三条提示只看词面。真正的切题是语义判断，规则算不出来，所以单独做成一个**可关闭**的模型判定：

```
POST /api/writing/review {text, subject, band, task, semantic: true}
→ dims 多一项 {key:"topic", name:"切题", verdict:"on_topic|partial|off_topic",
               label:"切题|部分切题|偏题", score, max:25, source:"model", evidence, reason}
→ coverage: "形式 + 语义切题"
```

模型可以编造，所以有三道闸，任何一道不过就整条作废、降级成「仅形式维度」并写明原因：

1. **判定只能是三个枚举值**——回 `good`、`优秀` 之类一律不认；
2. **证据必须是原文**——忽略空白和标点后仍要能在正文里找到，改写或引用题目都算伪造；
3. **分数锁在判定区间**——偏题 ≤8、部分切题 9–17、切题 ≥18；模型给 25 也会被压回 8。

没有题目时不做判断（没有可对照的要求），直接记一条 note。

## 验证

- `tests/test_writing.py` 28 项：形式维度 14 项 + 模型内容维度 6 项 + 语义切题 8 项（真证据保留、伪造证据拒绝、结论压分、坏 JSON 降级、无题目不判、标点差异容忍、未知结论拒绝、关闭时不调用）
- `tests/test_item_api.py` 增加一条 HTTP 测试：返回 4 个 `rule` 维度且总分等于各维之和
- Node 测试覆盖面板渲染

## 边界

- **默认只评形式**。切题要显式勾选语义判定，且只判「是否写题目要求的内容」，不判立意高低与文采；判定未经教师校准。
- 目标字数按学段写死，未按具体题目要求调整。
- 没有错别字/病句检测（需要词典与句法分析），没有手写识别。
- 分数只用于自我诊断，不是评分标准，不能当考试成绩。
