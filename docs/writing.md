# 写作分项评分

数学题可以对答案，作文不能。但作文也不是只能交给模型拍脑袋——**篇幅、结构、连贯、句式**这四件事可以确定性地算出来，而且能说清「为什么扣分」。

## 每条结论都要带证据

不是「结构 3 分」，而是：

```
篇幅   4/25   117 远低于目标（20%）
结构  25/25   3 段，平均每段 2.0 句
连贯  25/25   过渡词 4 处（每百词约 3.4 处）
句式  25/25   平均句长 19.5，长短有变化（标准差 3.6）
```

证据由规则生成，可复现、可单测，不经过模型。

## 四个形式维度（各 25 分）

| 维度 | 英语 | 语文 |
|---|---|---|
| 篇幅 | 词数 / 学段目标（40 / 80 / 120） | 汉字数 / 目标（300 / 600 / 800） |
| 结构 | 段数 ≥ 3 且每段 ≥ 2 句 | 同 |
| 连贯 | 过渡词密度（however/therefore/because…） | 过渡词（因此/然而/首先/总之…） |
| 句式 | 平均句长 8–22 词，长度有变化 | 平均句长 12–45 字，长度有变化 |

## 内容维度：模型或老师，且必须标明来源

`use_model=true` 时调用一次模型，评「内容切题/语言质量」（语文为「内容立意/语言表达」），各 25 分。
每条结果带 `source: "model"`，理由必须指向文本具体位置；模型返回不完整、解析失败、未配置时**静默降级**为只有形式维度，并在 `notes` 里写明，不冒充评过内容。

`coverage` 字段直接说清这次覆盖到哪一层：`仅形式维度` / `形式 + 内容`。

## 接口

```
POST /api/writing/review
{"subject":"语文","band":"middle","task":"记一次难忘的经历","text":"…","use_model":false}
→ {"total":79,"max":100,"coverage":"仅形式维度",
   "dims":[{key,name,score,max,source,evidence},…],
   "features":{units,sentences,paragraphs,avg_sentence,sentence_sd,connectives,punct_kinds},
   "notes":["未启用模型评分：本次只覆盖…"]}
```

界面在学习记录页底部：选学科/学段、填题目、贴作文 → 评一评；勾选「让模型评内容」才会多一次调用。

## 验证

- `tests/test_writing.py` 15 项：中英字数统计、短篇扣分证据、单段识别、无过渡词得 0、好文章 ≥70、总分为各维之和、空文本为 0、结果确定、模型维度合并与标注、坏输出降级、维度缺失拒绝、分数截断、默认不调模型
- `tests/test_item_api.py` 增加一条 HTTP 测试：返回 4 个 `rule` 维度且总分等于各维之和
- Node 测试覆盖面板渲染

## 边界

- **只评形式**。切题、立意、文采、语法错误都不在这里；勾选模型也只到「内容/语言」两维，且未经教师校准。
- 目标字数按学段写死，未按具体题目要求调整。
- 没有错别字/病句检测（需要词典与句法分析），没有手写识别。
- 分数只用于自我诊断，不是评分标准，不能当考试成绩。
