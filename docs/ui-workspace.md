# 学习工作区 UI 调整

## 范围

基于 main `c62e6bf399af929bde0c333ae2ffc81465f29a97`。这是独立的前端改动，不包含 `perf/token-budgeted-tutor` 分支的后端优化，也不修改数据库结构、教学规则、模型请求或答案授权。

延续现有纸白、墨蓝、钴蓝、宋体标题、细线和希腊建筑语言；不新增前端框架或运行时依赖。

## 使用变化

- 答疑页以对话和输入区域为主。历史可以收起，专注模式隐藏两侧辅助信息；窄屏同时只打开一个辅助抽屉。
- 当前题、提示进度与下一步操作放在右侧。看过完整解法与独立解出使用不同文案，前者不显示为独立掌握。
- 错题本优先显示到期安排，提供第一道复习题入口；学生原作答保持可见，参考答案和解析默认折叠。这是展示层的折叠，不是答案访问权限控制。
- 学习记录的规则说明默认折叠，证据历史仍可打开。窄屏分行显示掌握度，审计表格在自己的容器内横向滚动。
- 首页最近会话和复习数来自本地现有 API。无历史且无到期任务时不显示额外入口；复习 API 失败不冒充“零个待复习”。

## 验证与边界

前端测试使用 Node 内置 test runner，不需要 npm 安装：

```sh
node --test tests/ui-*.test.mjs
node --check static/js/app.js
```

完整后端回归：

```sh
python -m unittest discover -s tests -v
python desktop/launcher.py --headless-check
```

本次 Windows 环境的原始基线和 UI 工作区均运行了 196 项 Python 测试，均为 3 项错误、3 项跳过，错误名称一致：`SettingsHTTPTest.tearDownClass` 以及 `MergeTest` 的两项数据库清理错误。没有把这次结果标记为全绿，也没有为了 UI 交付混入后端测试修复。具体运行日志和前端最终数量以交付包中的记录为准。

实际浏览器验收覆盖浅色、深色、375/768/1024/1440px 宽度，以及短窗口首页、抽屉可见性、同路由选择、答案折叠、复习入口和流式期间切换会话。检查抽屉时必须同时验证 `hidden`、计算后的 `display` 和可见尺寸，不能仅检查布尔状态。

浏览器截图使用独立 `preview-data` 数据目录及离线模型示例。为测试“有到期任务”而调整的日期只用于这个测试目录；不是用户真实学习记录，不构成教学效果评测。测试数据库不进入补丁或源码提交。

本轮没有生成 Windows/macOS 安装包。可从独立 PR 审阅并合并，不直接覆盖 main。
