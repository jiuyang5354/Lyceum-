# 题库与在线难度标定

推荐原先只能说到「练 整式的乘法」，说不出「练哪一道、为什么是这道」。这一层补的就是这两件事。

## 题库 v1

`lyceum/items.json`：**507 道题、76 个知识点**，覆盖数学（小学/初中/高中）、物理、化学、生物、地理。

只收**能用数值或分数确定性判分**的题：乘法、加减、周长、一元一次方程、二元一次方程组、因式分解、一元二次方程、整式乘法、勾股定理、分数加减、百分数、三角形面积、等差数列、等比数列、概率、欧姆定律、电功率、密度、压强、相对分子质量、物质的量。

第三批补齐的是「有题可练但库里没有」的主干，并新开两个学科：

| 学科 | 新增知识点 |
|---|---|
| 小学数学 | 有余数的除法、多边形的面积、单位换算、平均数、时间与钟表、人民币、行程问题 |
| 初中数学 | 平方差（常数项）、完全平方（一次项系数）、科学计数法、中位数 |
| 高中数学 | 对数、指数方程、特殊角三角函数、组合数与二项式系数 |
| 初中物理 | 串联/并联电阻、机械效率 |
| 高中物理 | 匀变速位移、动能、动量 |
| 初中化学 | 质量守恒、分子原子计数 |
| 高中化学 | 气体摩尔体积、pH |
| 生物 | 细胞分裂、显微镜放大倍数、遗传概率、能量传递、呼吸与心率 |
| 地理 | 比例尺、人口密度、气温递减与年较差、时差、正午太阳高度、等高线 |

每题带 `params`（模板参数），`tests/test_itembank.py` 用 params **独立复算一遍答案**——答案写错会在测试里炸，不是靠人眼校对。

不接受的范围：作文、阅读理解、实验设计、几何证明——判不了就不进库，也不假装能判。

## 难度从哪来

两个来源，泾渭分明：

1. **结构先验 `difficulty_prior`**：学段基准（小学 0.22 / 初中 0.44 / 高中 0.62）+ 步骤数 + 运算个数，截断在 0.10–0.95。这是起点，**不是标定结果**。
2. **在线难度标定**：每次作答后按 1PL 形式的逻辑函数
   $$p = \frac{1}{1+e^{-K(\theta - d)}}$$
   更新题目难度 `d` 与学生能力 `θ`：做对 → 题比预想的简单（d 下降）、人比预想的强（θ 上升）；步长 `0.12 / (1 + n/10)` 随该题作答次数衰减。

这是 Elo 式在线标定，**不是 IRT 参数估计**；没有真实作答时它等于先验，这一点不掩盖。

## 选题

目标难度取「预计做对 75%」：`d* = θ - ln(3)/K`。在所有候选题里取 `|d - d*|` 最小的一道，同难度时优先没做过的。理由直接可读：

> 难度 0.58，接近你当前 0.55（预计做对 76%），3 步

## 接口

```
GET  /api/practice/next?subject=数学&topic=整式的乘法[&exclude=id1,id2]
     → {"item": {id, stem, unit, steps, difficulty}, "why": "...", "theta": 0.55}
     答案与 params 不下发。

POST /api/practice/answer {"item_id": "...", "answer": "51"}
     → {"correct": true, "expected": "51", "difficulty_before": 0.58, "difficulty_after": 0.53,
        "attempts": 1, "skill": {...}}
     判不了返回 409，不猜。
```

作答同时写一条 BKT 证据（`variant_right` / `variant_wrong`），所以掌握度与题目难度一起动。

`/api/review/today` 的 `next` 现在会带一道具体题（同样不含答案），首页卡片显示为：

```
下一步 · 数学  整式的乘法 还没稳（0.60 < 0.85），先补这一步再看 因式分解
试一题 · 难度 0.58   展开 (3x + 8)(5x + 9)，一次项系数是多少？
  [ 写下答案，不用写单位 ]  [对答案]
```
输入后当场判分：对 → 绿色「对了。难度 0.58 → 0.49」，错 → 红色并给出参考答案；**不自动换题**，学生点「下一题 →」才继续。

## 存储

新增两张表（只加不删）：

- `item_stats(item_id, attempts, correct, difficulty, first_seen, updated)` —— 当前标定结果
- `item_attempts(item_id, subject, topic, correct, answer, theta_before, difficulty_before, difficulty_after, ts)` —— 逐次作答审计

## 验证

- `tests/test_itembank.py` 20 项：每题答案可复算、先验单调、θ/难度映射、选题最近、排除生效、判分（分数与小数等价、单位容错）、标定方向与步长衰减、数据库累加
- `tests/test_item_api.py` 4 项：下一题不泄答案、判分写回难度与掌握度、未知知识点 404、review/today 带具体题
- UI 测试：卡片显示题干与难度

## 边界

- 507 道题覆盖 76 个知识点，但生物/地理各只有 20 余题，语文/英语/历史/道德与法治仍没有可确定性判分的题；题库仍是最薄的一层。
- 先验难度来自结构启发式，没做过 IRT 校准；在线标定要真实作答才会偏离先验。
- 没有区分度参数、没有猜测参数、没有等值（equating）；跨学期难度不可比。
